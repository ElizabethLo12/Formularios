formularios en HTML

Texto

Campos de texto básicos: simple, con placeholder, obligatorio (requiered), de solo lectura (readonly) y deshabilitado (disabled).



Contacto

Campos especializados para datos de contacto: contraseña, correo electrónico, teléfono y URL, cada uno con su propio teclado y validación el navegador





Numéricos

Campos para valores numéricos: un numero con límites (min/max) y un deslizador (range) para elegir un valor dentro de un rango.


Fecha y hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semana del año y mes.






Selección

Controles de selección: elegir un color, marca una casilla, elegir una opcion de un grupo de radios y subir un archivo.





Listas desplegables (select)

Listas desplegables con el elemento select: una opción simple, una con valor preseleccionado (selected), una agrupada con optgroup, una seleccion multiple (multiple) y una deshabilitada (disable).
